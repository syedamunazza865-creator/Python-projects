# Section 11: Capstone Project — Student Result Management System

## About This Project

The ultimate Python project that combines EVERY concept
learned throughout the entire course!

This is a complete real world application —
not just a simple script!

---

## 📋 Features

- ✅ Add students with marks for 5 subjects
- ✅ Auto calculate total, percentage and grade
- ✅ Save all data permanently to CSV
- ✅ View all students with full details
- ✅ Search student by name
- ✅ Generate class performance statistics
- ✅ Create visual performance charts
- ✅ Handle all errors gracefully
- ✅ Data persists after closing program

---

## 🚀 How to Run

```bash
# Install required libraries
pip install pandas matplotlib

# Run the system
python student_results.py
```
