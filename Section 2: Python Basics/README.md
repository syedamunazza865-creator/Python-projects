## Mini Project — Student Report Card

Takes marks for 5 subjects and generates a complete report card!

```python
name = input("Enter student name: ")
maths = float(input("Mathematics: "))
# ... more subjects
total = maths + science + english + hindi + computer
percentage = total / 5
print(f"Percentage: {percentage}%")
```
